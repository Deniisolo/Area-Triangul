# 🔺 Cálculo del área de un triángulo

Este programa calcula el área de un triángulo usando la fórmula:  
**(base × altura) / 2**

## 📄 Código

let base = 10;
let altura = 5;

let area = (base * altura) / 2;

console.log("El área del triángulo es: " + area);

## Resultado esperado
El área del triángulo es: 25

Para correr el código de JavaScript en tu máquina local, necesitas tener Node.js instalado.
